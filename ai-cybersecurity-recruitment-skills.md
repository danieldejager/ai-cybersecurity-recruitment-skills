# AI Cybersecurity Recruitment Skills & Udemy Courses

Private reference for recruiting cybersecurity talent who can handle AI systems.

## Core Skills Required

### AI-Specific Technical Skills
- Prompt injection defense and jailbreak testing (direct and indirect)
- LLM red teaming with tools like NVIDIA Garak and Microsoft PyRIT
- Threat modeling using MITRE ATLAS
- Adversarial machine learning — data poisoning, model inversion, evasion attacks
- Securing agents and tools — least-privilege permissions, MCP security, output validation
- AI supply chain — model scanning, SBOMs, poisoned dependencies
- RAG and pipeline security

### Governance and Frameworks
- OWASP LLM Top 10
- NIST AI Risk Management Framework
- ISO 42001 and EU AI Act basics
- Shadow AI detection and policy

### Foundational Skills Still Required
- Python
- Cloud security
- Traditional incident response, SIEM, and identity work
- Critical thinking and clear communication — because AI outputs need human judgment
